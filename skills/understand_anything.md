# SKILL ADAPTER: UNDERSTAND ANYTHING

> Multi-agent codebase mapping, onboarding, and interactive visual tours.

## Overview
- **Trigger**: Developer or agent unfamiliar with a large codebase; initial intake of an existing project; answering "where do I start?".
- **Pipeline Stage**: `Discovery & Onboarding`
- **Output**: Structural graph, plain-English subsystem explanations, guided exploration tours.

## Core Capabilities
1. **Multi-Agent Deep Parse**: Deconstructs unfamiliar codebases into hierarchical functional layers.
2. **Visual Dashboard**: Interactive dashboard for panning, zooming, and querying classes, functions, and files.
3. **Plain-English Synthesis**: Generates conversational explanations of complex system interactions without code overload.

## Execution
```bash
# Analyze current repository and launch interactive exploration
understand-anything .
```
